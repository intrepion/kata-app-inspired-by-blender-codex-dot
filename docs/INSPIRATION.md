# Blender inspiration research

Checked 2026-11-10 using official primary sources.

- [Blender modeling](https://www.blender.org/features/modeling/) describes creating, transforming, sculpting and editing models. Formyard takes only the approachable primitive-and-transform loop: add shapes, arrange them in 3D, inspect from different angles, export a mesh. The direct page fetch failed; its official page content was available in search indexing.
- [Blender modifier introduction](https://docs.blender.org/manual/en/3.6/modeling/modifiers/introduction.html) describes non-destructive geometry operations. Formyard intentionally does not implement a modifier stack, mesh edit mode, subdivision, or Geometry Nodes. Transform parameters remain editable without baking until OBJ export.

Formyard uses an original cream-and-forest visual identity, a procedural still life built from basic shapes, custom Canvas rendering, and no Blender logos, screenshots, code, branding, or asset files. It is an independent learning kata, not a compatible or affiliated Blender product.
